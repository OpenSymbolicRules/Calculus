## Findings

### `calculus.derivative.power`

- counterexample: at n = 0 and x = 0, x^0 is defined around 0 but n * x^(n - 1) = 0 * x^(-1) is undefined at 0, so the v0.1 rule, whose only condition is FreeQ, fails there (Lean theorem derivPow_counterexample). It would hold with the condition n ≠ 0.

### `calculus.derivative.ln`

- complex: not proved; ln is defined for z ≠ 0 but the principal logarithm is not differentiable on the negative real axis (its branch cut), so the statement fails there.

### `calculus.derivative.arctan`

- complex: not proved; the mapping of transc1#arctan to Complex.arctan is provisional.

### `calculus.derivative.arctanh`

- real: Mathlib has no derivative lemma for Real.artanh at this revision; the proof derives it from artanh x = 1/2 log((1 + x)/(1 - x)) on (-1, 1).
